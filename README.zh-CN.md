# Goose of Mischief

[English](README.md)

一个图片编辑 Skill：在保留原图构图、镜头、主体关系和场景身份的前提下，将整张图片重构为强烈清晰的低多边形田园绘本世界，并自然植入一只按真实比例融入场景、正在进行无害恶作剧的白鹅。

## 核心能力

- 必须基于用户上传的参考图工作。
- 保留原图比例、裁切、镜头、透视、主体、空间关系和场景身份。
- 将全部主体重新构造成物体级低多边形造型，而不是简单套滤镜。
- 使用哑光平涂材质、克制的原图衍生田园配色、柔和环境光和清晰轮廓。
- 每次默认植入且只植入一只鹅。
- 根据构图自动判断鹅应该明显、轻微还是隐藏。
- 使用附近具有现实尺寸的物体判断鹅的合理比例。
- 当空间无法容纳完整鹅时，使用远景、局部遮挡或画面边缘裁切。
- 避免把照片处理成满屏统一三角形碎片的伪低多边形滤镜。

该 Skill 不复制商业游戏的具体地图、角色模型、资产、Logo、UI、截图、任务列表或标题设计。

## 工作方法

Skill 使用五阶段流程：

1. **拆解原图**：识别主体、尺度、透视、层级、遮挡、光线、颜色和保护区域。
2. **选择性保留**：锁定构图、镜头、主体位置、视觉主次和场景身份。
3. **风格重构**：把完整场景重建为干净的低多边形田园绘本世界。
4. **鹅的融入**：确定深度层级、支撑面、真实比例、遮挡方式、显眼程度和恶作剧动作。
5. **质量检查**：拒绝风格过弱、构图漂移、三角滤镜、比例错误或贴图感。

## 视觉示例

经过筛选的参考图可以直接放在 [`assets/examples/`](assets/examples) 中。

保持简单即可：

- 放入少量高质量最终成品图
- 每次只参考其中最相关的 1–3 张
- 示例用于稳定画风、鹅的比例和物理融入方式
- 示例不能覆盖用户原图的优先级，也不能被直接照搬

不需要 manifest，也不需要单独的 `style-anchors` 目录。

## 安装

### Codex

```bash
git clone https://github.com/Yipxiyi/Goose-of-Mischief.git \
  ~/.codex/skills/goose-of-mischief
```

### 其他支持 Skill 的 Agent

将仓库克隆到对应 Agent 的 skills 目录，并确保它可以读取根目录中的 `SKILL.md`。

## 使用方法

上传图片后输入：

```text
用 $goose-of-mischief 改造这张图片，保留原本构图，并自动判断鹅应该有多明显。
```

```text
用 $goose-of-mischief 处理这张宠物照片，鹅的比例必须合理，恶作剧轻微一点。
```

```text
用 $goose-of-mischief 处理这张产品图，不要挡住标签。如果完整鹅放不下，就只让鹅从画面边缘探头。
```
