# Goose of Mischief

[English](README.md)

一个图片编辑 Skill：用户上传任意图片后，在严格保留原始构图、镜头、主体关系和场景身份的前提下，将整张图片重构为**强烈清晰的低多边形田园绘本世界**，并自然植入一只按真实比例融入场景、正在进行无害恶作剧的白鹅。

视觉语言明确参考《Untitled Goose Game》所代表的广义风格特征：简化低多边形体块、哑光平涂材质、柔和田园配色、无五官人物、清晰轮廓、柔和环境光和冷面式物理喜剧。

该 Skill 不复制商业游戏的具体地图、角色模型、关卡布局、资产、Logo、UI、截图、任务列表或标题设计。

## 核心能力

- 必须基于用户上传的参考图工作。
- 保留原图画幅比例、裁切、镜头、透视、主体数量、空间关系、视觉主次和场景身份。
- 将全部主体重新构造成物体级低多边形造型，而不是简单套滤镜。
- 使用哑光平涂表面、柔和环境光、低密度细节和克制的原图衍生田园配色。
- 每次默认植入且只植入一只鹅。
- 根据构图自动判断鹅应当是**明显、轻微还是隐藏彩蛋**。
- 通过真实尺度参照物判断鹅的大小，避免巨大吉祥物或微型玩具感。
- 当空间无法容纳完整鹅时，使用远景、局部遮挡或画面边缘裁切。

风格必须第一眼就明显，不能仍然像一张只做了轻微处理的照片。

## 工作方法

Skill 使用五阶段流程：

1. **拆解原图**：识别主体、尺度关系、结构轴、层级、遮挡、光线、颜色和保护区域。
2. **选择性保留**：锁定构图、镜头、主体位置、视觉主次和场景身份。
3. **风格重构**：把所有物体重建为干净的低多边形田园绘本世界。
4. **鹅的融入**：确定深度层级、支撑面、尺度参照物、遮挡方式、显眼程度和恶作剧动作。
5. **质量检查**：拒绝风格过弱、三角滤镜、构图漂移、比例错误或贴图感。

## 强风格规则

应使用：

- 物体级简化低多边形造型
- 大面积干净色面
- 哑光、粉笔感、手绘感平涂材质
- 略显笨拙和块状的比例
- 成团植物体块
- 原图存在人物时，将其简化为无五官绘本人物
- 柔和环境光
- 短而柔和的接触阴影
- 奶油色、鼠尾草绿、苔藓绿、石材米色、浅灰蓝、风化木棕、陶土色、砖红和芥末黄等克制色彩角色

禁止使用：

- 轻微照片滤镜
- 满屏统一三角形马赛克
- 彩色玻璃、水晶或折纸碎裂效果
- 高光泽 3D
- 电影感光照
- 用普通水彩、油画、矢量海报或抽象编辑风格替代目标视觉语言

## 鹅的真实比例与显眼程度

不得使用“占图片短边百分比”来决定鹅的尺寸。

Skill 必须：

1. 选择前景、中景或背景层级
2. 找到真实可用的支撑面
3. 使用至少两个附近物体作为现实尺度参照
4. 判断完整成年鹅是否真的放得下
5. 若放不下，改用局部遮挡、远景或边缘裁切

显眼程度只能通过位置、轮廓对比、动作、互动、层级和遮挡控制，不能通过不合理放大或缩成玩具控制。

## 视觉参考资产

仓库使用两类视觉参考：

- `assets/style-anchors/`：定义统一的低多边形绘本画风、材质、光照、人物和鹅的造型。
- `assets/examples/`：保存经过验收的原图／结果图配对，用来展示构图保留、尺度判断、遮挡和恶作剧融入方式。

图片目录本身不会自动提高质量。示例必须经过筛选，并由 Skill 明确作为视觉锚点使用。

优先级始终是：

1. 用户上传的原图和要求
2. 原图构图、尺度与保护区域
3. `SKILL.md` 和详细 Prompt
4. 视觉参考资产

视觉参考只能学习画面语言和转换方式，不能复制示例中的主体、具体构图、配色、地点或恶作剧动作。

建议只维护 4–6 组高质量案例，而不是堆积大量普通示例。所有图片应为原创、专门生成、公共领域或获得适当授权的内容，不应使用私人照片或商业游戏截图。

## 安装

### Codex

```bash
git clone https://github.com/Yipxiyi/Goose-of-Mischief.git \
  ~/.codex/skills/goose-of-mischief
```

### 其他支持 Skill 的 Agent

将仓库克隆到对应 Agent 的 skills 目录，并确保它可以读取根目录中的 `SKILL.md`。

## 使用方法

上传图片后输入：

```text
用 $goose-of-mischief 改造这张图片，保留原本构图，并自动判断鹅应该有多明显。
```

```text
用 $goose-of-mischief 处理这张宠物照片，强烈保留低多边形田园绘本风格，鹅的尺寸必须符合真实比例。
```

```text
用 $goose-of-mischief 处理这张产品图，不要挡住标签。如果完整鹅放不下，就只让鹅从画面边缘探头。
```
