# Goose of Mischief

[English](README.md)

一个图片编辑 Skill：用户上传任意图片后，在保留原始构图、主体和场景身份的基础上，将整张图片转换为原创的田园低多边形绘本质感，并自然地植入一只正在进行无害恶作剧的白鹅。

## 核心能力

- 必须基于用户上传的参考图工作。
- 保留原图比例、裁切、镜头、主体数量、空间关系和地点特征。
- 将整张图片转换为柔和低多边形、哑光手绘材质、克制配色与柔光效果。
- 每次默认植入且只植入一只鹅。
- 根据原图构图自动判断鹅应该是**明显、轻微还是隐藏彩蛋**。
- 优先利用原图已有物品设计恶作剧，而不是重做场景。
- 自动匹配鹅的透视、比例、光照、遮挡关系与接触阴影，避免贴图感。

该 Skill 使用原创视觉规则，不复制任何商业游戏的具体地图、角色模型、Logo、UI、截图或标题设计。

## 使用方法

上传图片后输入：

```text
用 $goose-of-mischief 改造这张图片，保留原本构图，并自动判断鹅应该有多明显。
```

```text
用 $goose-of-mischief 处理这张人物照，鹅藏得轻微一些，不要挡住人物面部。
```

```text
把这张旅行照转换成田园低多边形绘本质感，让鹅的恶作剧明显一点。
```

## 工作流程

1. **构图锁定**：识别主体、镜头、裁切、保护区域和场景身份。
2. **整体风格转换**：处理几何、材质、颜色、植物和光照。
3. **植入恶作剧鹅**：决定鹅的大小、深度层级、可见程度、位置和动作。
4. **质量检查**：确认原图仍可辨认，并检查鹅的透视、阴影、遮挡与动作是否自然。

## 鹅的可见程度

| 模式 | 适用情况 | 大致尺寸 |
| --- | --- | --- |
| 明显 | 宽阔场景、有较多留白、原图本身有动作 | 图片短边的 8%–18% |
| 轻微 | 人像、产品、宠物、室内、食物等主体明确的图片 | 3%–8% |
| 隐藏彩蛋 | 构图密集、全景、建筑、风景或氛围较庄重的图片 | 1%–4% |

用户可以直接指定可见程度，未指定时由 Skill 自动判断。

## 恶作剧逻辑

优先使用原图已有的次要物品，例如：

- 叼走帽子、袜子、勺子、钥匙、花朵或玩具
- 拉扯鞋带、围巾、桌布、软管、丝带或背包带
- 推动杯子、篮子、球、靠垫、鞋子或小容器
- 打乱整齐排列的物品
- 躲在家具或植物后方准备偷东西
- 在画面边缘悄悄抢镜

恶作剧必须无害、容易理解，并且不能覆盖原图的主要叙事。
