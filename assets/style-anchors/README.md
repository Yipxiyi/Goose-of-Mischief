# Style Anchors

Place four to six approved finished images in this directory.

## Recommended coverage

- one outdoor garden or village environment
- one indoor scene
- one scene containing a faceless person
- one pet or other-animal scene
- one dense or distant hidden-goose composition
- one object or product-centered composition

## Selection criteria

Every anchor must show:

- strong object-level low-poly reconstruction
- broad clean shapes rather than triangular mosaic filtering
- matte flat-painted surfaces
- soft ambient light and short contact shadows
- restrained source-derived pastoral colors
- exactly one anatomically plausible goose
- dry, harmless mischief

Reject anchors with:

- photographic texture remaining dominant
- glossy 3D or cinematic lighting
- oversized mascot goose
- miniature toy goose
- floating feet or missing contact shadow
- copied game maps, screenshots, UI, logos, or protected assets

## Runtime use

Use only two or three anchors per transformation. Too many references can average away the intended style.

Learn only the rendering grammar. Never copy an anchor's subjects, exact scene layout, colors, prop arrangement, or prank.
